**Design Spec:** `DESIGN.md` v2.1.0 ("Soft Arcade")

## Executive Summary

Audit conducted across all CodeQuest landing page files (`page.tsx`, `HeroSection.tsx`, `PipelineSection.tsx`, `QuestShowcaseSection.tsx`, `QuestBubble.tsx`, `SquadSection.tsx`, `LeaderboardSection.tsx`, `PlayerPebble.tsx`, `ArcadeStar.tsx`, `OnboardingSection.tsx`, `Header.tsx`, `globals.css`).

The landing page implements a distinctive "Soft Arcade" visual language (Ink Navy `#141925`, Warm Cream `#FFF3DE`, Warm Amber `#FFAE58`, 4-point arcade star ✦, tactile offset bevel shadows) and avoids generic AI slop templates (no bento-grid mosaic, no generic 3-step "how it works", no fake testimonials, no generic 4-column mega footer).

However, **18 distinct findings** were identified across three priority tiers:
- **8 HIGH Priority Findings (Hard Gate violations):** Metadata em dash (`—`), unverified precision statistic (`100% Mentor Kampus`), simulated squad/podium users lacking visible `[SIMULASI]` labels, missing zero-data empty states, missing `cursor: pointer` in base CSS, theme toggle mismatch between Header and dark-locked landing canvas, dead query parameter link in QuestBubble, sub-44px touch targets on mobile links.
- **5 MEDIUM Priority Findings (Purpose-Gate violations):** Endless pulsing status dots contradicting MOTION 1 dial, generic AI `<Sparkles>` icon on CTA button, arrow cues (`→` / `<ArrowRight>`) on almost every button/link, repetitive uppercase eyebrow pills above headings, and render-blocking external Google Font `@import`.
- **5 LOW Priority Findings (Quality Locks & Craftsmanship):** Metadata AI buzzword ("journey"), clickable hover affordance on non-clickable leaderboard rows, sub-AAA text opacity over amber backgrounds, and redundant image alt text on skill badges.

## Numbered Findings List

### Finding #1
- **Component & Location:** `src/app/page.tsx` (Line 19)
- **Rule Cited:** R-02 (Copywriting — Em Dash Character Ban)
- **Priority:** HIGH
- **Reason:** Metadata `title` contains em dash character (`—`): `'CodeQuest — Gamified Coding Platform for Cyber University'`.
- **Recommended Remedy:** Replace em dash with colon (`:`) or hyphen (`-`), e.g., `title: 'CodeQuest: Gamified Coding Platform for Cyber University'`.

---

### Finding #2
- **Component & Location:** `src/components/landing/HeroSection.tsx` (Line 141)
- **Rule Cited:** R-17 (Data & Numbers) / R-36 (No Fabricated Claims)
- **Priority:** HIGH
- **Reason:** Telemetry card displays precision claim `"100% Mentor Kampus"` under "Review Terverifikasi" without an empirical measurement or verifiable data source.
- **Recommended Remedy:** Replace with factual qualitative text, e.g. `"Kurasi Mentor Kampus"` or `"Review Admin & Mentor"`, omitting the fabricated `100%` statistic.

---

### Finding #3
- **Component & Location:** `src/components/landing/SquadSection.tsx` (Lines 72–132) & `src/app/page.tsx` (Lines 84–96)
- **Rule Cited:** R-38 (Real Content or Honest Placeholder) / R-23 (Clarification & Visual Assets)
- **Priority:** HIGH
- **Reason:** Squad Lobby simulation features fictional user personas (`Alex Dev`, `Budi Runner`, `Citra Code`) with live-style indicators (`READY`, `3 / 3 SLOTS`, `animate-pulse`) with no visible "Simulasi" / "Preview" label.
- **Recommended Remedy:** Add a prominent, honest tag `[PREVIEW LOBI]` or `[SIMULASI FITUR]` to the Squad Lobby header so prototype visuals are never disguised as live telemetry.

---

### Finding #4
- **Component & Location:** `src/app/page.tsx` (Lines 66–77, 84–96) & `src/components/landing/QuestShowcaseSection.tsx`
- **Rule Cited:** R-27 (UI States — Missing Honest Empty State)
- **Priority:** HIGH
- **Reason:** If database queries succeed but return zero active quests or zero leaderboard users, the page silently renders hardcoded fallback mock arrays rather than providing an honest empty state.
- **Recommended Remedy:** Provide an explicit empty state component for catalog and leaderboard (e.g., `"Belum ada quest aktif musim ini"` / `"Musim baru: jadilah yang pertama merebut poin"`) when live data length is 0.

---

### Finding #5
- **Component & Location:** `src/app/globals.css` (Lines 171–182)
- **Rule Cited:** R-39 (Accessible Semantics & Interaction Affordances)
- **Priority:** HIGH
- **Reason:** Base CSS layer does not define `cursor: pointer` on interactive elements (`a[href]`, `button`, `[role="button"]`), violating mandatory base interaction affordance.
- **Recommended Remedy:** Add `cursor: pointer;` to `button, [role="button"], a[href], input[type="submit"]` and `cursor: not-allowed;` to `:disabled` inside `@layer base`.

---

### Finding #6
- **Component & Location:** `src/components/Header.tsx` (Line 125) & `src/app/globals.css` (Lines 68–91)
- **Rule Cited:** R-34 (Every Theme You Ship Must Work) / R-21 (Dark Mode Consistency)
- **Priority:** HIGH
- **Reason:** Header provides an active `<ThemeToggle />`, but `.soft-arcade` on the landing page container hardcodes dark Ink Navy (`#141925`). Switching to Light mode turns Header stark white (`#FFFFFF`) with purple borders while the landing page directly below remains dark Ink Navy, breaking visual continuity.
- **Recommended Remedy:** Either scope `.soft-arcade` with light/dark adaptive variables conforming to DESIGN.md, or hide/disable the theme toggle on the landing page if Soft Arcade is strictly a dark-canvas experience.

---

### Finding #7
- **Component & Location:** `src/components/landing/QuestBubble.tsx` (Lines 62, 118–124)
- **Rule Cited:** R-26 (Interactive Elements — Dead Control / Unhandled Query)
- **Priority:** HIGH
- **Reason:** Card action button navigates to `/explore?quest=${id}`, but `/explore` page (`src/app/explore/page.tsx`) only parses `q`, `difficulty`, `sort`, and `page`; the `quest` query parameter is ignored and the specific quest is neither filtered nor highlighted.
- **Recommended Remedy:** Link directly to the dedicated quest detail route `/quests/${id}` which already exists in `src/app/quests/[id]/page.tsx`.

---

### Finding #8
- **Component & Location:** `src/components/landing/QuestBubble.tsx` (Line 120) & `src/app/page.tsx` (Lines 143–156)
- **Rule Cited:** R-03 (Mobile Responsiveness — Touch Target Minimums)
- **Priority:** HIGH
- **Reason:** QuestBubble CTA button uses `py-2.5` without `min-h-[44px]` (computed height ~40px). Footer navigation links in `page.tsx` have `text-xs` without padding, resulting in tap target height of ~16px, violating the 44px mobile touch target rule.
- **Recommended Remedy:** Add `min-h-[44px]` to QuestBubble CTA and add vertical tap padding (`py-2.5 px-2`) to footer navigation links.

---

### Finding #9
- **Component & Location:** Multiple landing components:
  - `src/components/landing/SquadSection.tsx` (Lines 33, 45, 57, 136, 170: `Zap`, `Users`, `Shield`, `CheckCircle2`, `ArrowRight`)
  - `src/components/landing/LeaderboardSection.tsx` (Lines 183, 192: `ArrowRight`, `Trophy`)
  - `src/components/landing/OnboardingSection.tsx` (Lines 56, 65, 67, 76, 85, 88: `LayoutDashboard`, `Sparkles`, `ArrowRight`, `LogIn`, `CheckCircle2`)
- **Rule Cited:** R-39 (Accessible Semantics — Decorative Icon ARIA)
- **Priority:** HIGH
- **Reason:** Multiple purely decorative Lucide icons lack `aria-hidden="true"`, causing screen readers to encounter unlabelled SVGs.
- **Recommended Remedy:** Add `aria-hidden="true"` to all decorative Lucide icon components across all landing sections.

---

### Finding #10
- **Component & Location:** `src/components/landing/HeroSection.tsx` (Line 99) & `src/components/landing/SquadSection.tsx` (Line 75)
- **Rule Cited:** R-19 (Animations — Endless Loops) / R-39 (Reduced Motion)
- **Priority:** MEDIUM
- **Reason:** Status indicators use perpetual `animate-pulse` loop without user trigger, conflicting with the declared calm motion dial (MOTION 1).

### Finding #11

- **Priority:** MEDIUM
- **Reason:** `<Sparkles>` icon used inside the primary "Buat Akun Sekarang" button, which is an archetype generic AI glyph tell.

### Finding #12
- **Component & Location:** `src/components/landing/HeroSection.tsx` (Lines 66, 84), `QuestShowcaseSection.tsx` (Line 72), `QuestBubble.tsx` (Line 122), `SquadSection.tsx` (Line 170), `LeaderboardSection.tsx` (Line 183), `OnboardingSection.tsx` (Line 67)
- **Rule Cited:** R-08 (Button Arrows — Overuse as Default)
- **Priority:** MEDIUM
- **Reason:** Arrows (`→`, `&rarr;`, `<ArrowRight>`) are appended to nearly every CTA button and tertiary link across all 6 sections.
- **Recommended Remedy:** Reserve arrows solely for primary forward-progression CTAs (Hero primary and Onboarding primary); remove arrows from list links, secondary buttons, and section headers.

### Finding #13
- **Component & Location:** `src/components/landing/HeroSection.tsx` (Line 34), `SquadSection.tsx` (Line 12), `LeaderboardSection.tsx` (Line 69), `OnboardingSection.tsx` (Line 31)
- **Rule Cited:** R-09 (Badges — Eyebrow Badge Above Headlines) / R-06 (Typography)
- **Priority:** MEDIUM
- **Reason:** Pill badge parked directly above headings repeating topic tags (`MODE MULTIPLAYER`, `REKOGNISI REPUTASI`, `GERBANG ONBOARDING`) with wide letter-tracking, creating template monotony across sections.
- **Recommended Remedy:** Remove redundant eyebrow pill badges where the H2 title already introduces the concept clearly; keep badges only for real game state (e.g. `SEASON 1 AKTIF`).

---

### Finding #14
- **Component & Location:** `src/app/globals.css` (Line 1)
- **Rule Cited:** R-40 (Performance — Render-blocking Remote Font)
- **Priority:** MEDIUM
- **Reason:** `@import url("https://fonts.googleapis.com/css2?family=Material+Symbols+Outlined...")` is render-blocking at the top of CSS and is completely unused by the landing page (which uses inline SVGs and Lucide).
- **Recommended Remedy:** Remove the CSS `@import` from `globals.css` and load Material Symbols asynchronously only within administrative views that actually require it.

---

### Finding #15
- **Component & Location:** `src/app/page.tsx` (Line 20)
- **Rule Cited:** R-16 (Copywriting & Buzzwords — "Journey")
- **Priority:** LOW
- **Reason:** Metadata description uses the banned Empty AI Vocabulary word "journey": `"Level up your developer journey through real-world software quests..."`.
- **Recommended Remedy:** Rephrase cleanly without marketing fluff, e.g. `"Selesaikan misi koding nyata, berkolaborasi dalam skuad mahasiswa, dan raih reputasi di CodeQuest Cyber University."`

---

### Finding #16
- **Component & Location:** `src/components/landing/LeaderboardSection.tsx` (Lines 104, 134, 157)
- **Rule Cited:** C-2 (Functional Completeness) / R-39 (Interaction Affordances)
- **Priority:** LOW
- **Reason:** Top 3 Leaderboard rows have hover brightness and background lifts (`hover:brightness-105`, `hover:bg-[#2B354D] hover:border-[#47577A]`) suggesting clickable button behavior, but are non-interactive `div` list items.
- **Recommended Remedy:** Either wrap each leaderboard row in a `<Link href={userProfileUrl}>` or remove hover state transitions so static items do not mimic clickable controls.

---

### Finding #17
- **Component & Location:** `src/components/landing/LeaderboardSection.tsx` (Line 116) & `src/components/landing/OnboardingSection.tsx` (Line 58)
- **Rule Cited:** R-25 (Color Contrast — WCAG AAA Compliance)
- **Priority:** LOW
- **Reason:** `DESIGN.md` mandates strict WCAG AAA compliance for Ink Navy on Warm Amber. Sub-labels with `text-[#141925]/80` (Rank 1 "(Juara Musim)") and `opacity-80` (Onboarding button username) drop contrast to ~6.1:1, failing the 7:1 AAA threshold.
- **Recommended Remedy:** Remove opacity modifiers on top of `#FFAE58` surfaces to preserve solid `#141925` text at 9.58:1 contrast.

---

### Finding #18
- **Component & Location:** `src/components/landing/LeaderboardSection.tsx` (Line 219)
- **Rule Cited:** R-39 (Accessible Semantics — Redundant Image Alt Text)
- **Priority:** LOW
- **Reason:** Digital badge images specify `alt={badge.name}`, while `badge.name` is rendered as visible text immediately below the image, causing screen readers to redundantly announce the name twice.
- **Recommended Remedy:** Set `alt=""` and `aria-hidden="true"` on the badge `<Image>` component since the adjacent text block provides the accessible name.
